# Site public en deux langues (français, anglais)

Le français reste à la racine (`/`), l'anglais est sous `/en/` (`/en/tarifs/`, `/en/chambres/double/`…). Les adresses gardent les mêmes mots français après `/en/` : aucune redirection, aucun lien existant ne change. Seul le site public est concerné (pas `/admin`, pas la page QR `/c/…`).

## Comment ça marche
- **Le texte français sert de clé.** Dans le code, `t('Réserver')` donne « Book now » sur `/en/`. Les traductions sont dans `src/i18n/en.json` (phrase française : phrase anglaise).
- **Une phrase non traduite s'affiche en français**, jamais vide. C'est le cas d'un texte modifié dans `/admin` : la page anglaise le montre en français jusqu'à ce que la nouvelle phrase soit ajoutée au dictionnaire.
- **Textes de `/admin`** (`content.default.json` + modifications enregistrées) : `getContent('en')` traduit chaque phrase par le dictionnaire ; prix, images, téléphones et liens ne sont jamais touchés (les prix restent ceux du français / de la base).
- **Textes de la base** (chambres, équipements) : les colonnes anglaises existent déjà (`label_en` des types de chambre et des équipements) et sont utilisées sur `/en/`. Aucun changement de base.
- Chaque page a ses balises `hreflang`, une URL canonique par langue, `<html lang>`, et le plan du site (`/sitemap.xml`) liste les deux versions. `public/llms-en.txt` est la version anglaise de `llms.txt`.
- Le formulaire de contact envoie sa langue : le courriel reçu par l'hôtel porte `[EN]` dans l'objet et une ligne « répondre en anglais ».

## Quand un texte change ou qu'une page est ajoutée
1. Écrire le texte français comme d'habitude (dans le code avec `t('…')`, ou dans `/admin`).
2. `npm run i18n:missing` liste les phrases sans traduction. Pour inclure les textes modifiés en production, exporter le contenu de `/admin` (JSON) et le passer en argument : `npm run i18n:missing -- contenu-prod.json`.
3. Ajouter les traductions dans `src/i18n/en.json`. Le test `tests/i18n.test.ts` échoue si une phrase du code ou du contenu par défaut n'est pas traduite.
4. Nouvelle page publique : créer `src/pages/en/<page>.astro` (4 lignes : importer la page française et l'afficher) et l'ajouter à `src/pages/sitemap.xml.ts`.

## Choix à valider (voir la PR)
- Rubrique « Séminaires » : « Seminars » (retenu) ou « Meetings & Events ».
- Adresses `/en/…` : mots français conservés (retenu), ou adresses anglaises (`/en/rooms/`, `/en/rates/`) avec redirections.
- Pas de redirection automatique selon la langue du navigateur (retenu : un sélecteur FR | EN dans l'en-tête).
- Moteur de réservation Octorate : le lien est le même dans les deux langues tant qu'on n'a pas l'adresse de l'hôtel avec le paramètre de langue.
